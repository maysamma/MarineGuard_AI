# MarineGuard AI Demo Notes

## Recommended case
Use a real marine image showing visible debris or a clearly visible environmental indicator. Enter a site near Jeddah/Red Sea coordinates that you are comfortable using for a public demo.

1. Open Dashboard.
2. Generate a simulated sensor anomaly for the same site in Sensors.
3. Submit the image and description.
4. Run analysis with Gemini or local Ollama vision configured.
5. Show the Vision Agent result and its limitations.
6. Show IoT/Data Agent and Historical/Trend Agent in the trace.
7. Show the Evidence Package and explainable Priority Score.
8. Open GIS and the case.
9. Open Verification Queue and verify the case.

## If no AI key is available
The system intentionally returns Needs Review rather than fabricating visual findings. You can still demonstrate report storage, sensor simulation, historical context, GIS, scoring, recommendations, and human verification.
